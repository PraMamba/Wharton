Tree/boosting models (RF/XGBoost) can capture non‑linearities and interactions (rest, travel, goalie effects, score effects), and can serve as an empirical benchmark. If they add only marginal lift, you can keep the core narrative and cite the ML model as validation; if they materially improve log loss/Brier and calibration, you can present a blended stack (interpretable base + ML residual).

2) 57.4% 5‑fold CV accuracy is reasonable for hockey. NHL games are high-variance and close to 50/50; strong public baselines (home-ice + team strength) often sit ~53–55% accuracy. More important: report uncertainty, class balance, and probability metrics (log loss, Brier, calibration curves), not just accuracy.

3) Best balance: regularized logistic regression (L1/L2/elastic net) with well-designed features + splines/interactions, or a GAM/EBM (Explainable Boosting Machine). These usually approach boosting performance while giving transparent, additive explanations; you can still add post-hoc SHAP for any XGBoost component. Use time-split CV to mimic forecasting and prevent leakage, and compare to a simple benchmark (home-ice + BT rating) and to sportsbook implied probabilities. If using boosting, constrain monotonic features and communicate via SHAP/partial dependence, then calibrate probabilities (Platt/isotonic). Report both discrimination and calibration plots.
